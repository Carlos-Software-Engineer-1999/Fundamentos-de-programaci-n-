# Ejercicios con Matrices en Java

## Descripción

Proyecto desarrollado en Java que contiene tres ejercicios prácticos sobre el uso de matrices (arreglos bidimensionales). Los programas permiten capturar información mediante consola, procesar datos y mostrar resultados de manera interactiva.

## Estructura del proyecto

```text
EjerciciosMatrices/
└── src/
    ├── Ejercicio1.java
    ├── Ejercicio2.java
    └── Ejercicio3.java
```

## Ejercicios desarrollados

### 1. Ventas de computadoras

Programa que permite registrar las computadoras vendidas por diferentes vendedores en distintas zonas.

Funcionalidades:
- Captura de vendedores y zonas.
- Registro de ventas mediante una matriz bidimensional.
- Identificación de la zona con mayores ventas.
- Identificación del vendedor con mayores y menores ventas.
- Cálculo del total general de computadoras vendidas.

### 2. Operaciones con una matriz 4 × 4

Programa interactivo mediante un menú de opciones.

Funcionalidades:
- Llenado de la matriz con números enteros sin repetir.
- Suma de filas y columnas.
- Suma de una fila o columna seleccionada.
- Identificación del número mayor y menor y sus posiciones.
- Conteo de números pares e impares.
- Generación de una matriz con los cuadrados de los valores.
- Suma de diagonales principal e inversa.
- Cálculo de la media aritmética.
- Validación para impedir operaciones antes de llenar la matriz.

### 3. Calificaciones de estudiantes

Programa que permite registrar las calificaciones de varios estudiantes en diferentes exámenes.

Funcionalidades:
- Captura de estudiantes y exámenes.
- Registro de calificaciones mediante una matriz bidimensional.
- Cálculo del promedio individual.
- Identificación de estudiantes con el mejor promedio, considerando empates.
- Listado de estudiantes con promedio entre 9 y 10.
- Listado de estudiantes con promedio inferior a 7.
- Identificación de los exámenes con mayor y menor promedio.

## Tecnologías utilizadas

- Java
- IntelliJ IDEA
- Matrices bidimensionales
- Arreglos
- Ciclos y estructuras condicionales
- Clase Scanner para entrada de datos por consola

## Ejecución

1. Abrir el proyecto en IntelliJ IDEA.
2. Configurar un JDK compatible.
3. Acceder a la carpeta `src`.
4. Ejecutar individualmente `Ejercicio1`, `Ejercicio2` o `Ejercicio3`.
5. Introducir los datos solicitados en la consola.

## Objetivo

Practicar la creación, manipulación y recorrido de matrices bidimensionales en Java, aplicando operaciones matemáticas, validaciones de datos y programación interactiva por consola.
